# IF CONDITION


If cause = condition 
\
Main cause = Result

#### Five Types:
- "0 Conditional"
- "1<sup>st</sup> Conditional" 
- "2<sup>nd</sup> Conditional"
- "3<sup>rd</sup> Conditional"
- "Mixed Conditional


## 0 Conditional

### `If + presente, + subject + Present Simple`

Si usa quando il presente è sempre vero come per ***abitudini*** o ***fatti scientifici***

## 1<sup>st</sup> Conditional
### `If + present simple, + subject + will + base form`

Si usa per esprimere ***ipotesi possibili***

## 2<sup>nd</sup> Conditional
### `If + past simple, + subject + would + base form`

Si usa per esprimere ***ipotesi impossibili o improbabili***

**REMEMBER: Would can be used with `may(+formal)/could/might`**

## 3<sup>rd</sup> Conditional
### `If + past perfect, + subject + would have + past participle`

Si usa per esprimere ***ipotetoche*** situazioni nel ***passato*** o per un ***rimpianto***

**REMEMBER: Would can be used with `may(+formal)/could/might`**

## Mixed Conditional 
***Insieme tra 2 e 3 conditional***

### ***1<sup>st</sup> Form***
### `If + past perfect, + subject + would + base form`

Si usa per immaginare ***come cambierebbe il presente*** se il ***passato fosse stato diverso***

**EXAMPLE: If I had bought the winning ticket, i would be rich *now***

### ***2<sup>nd</sup> Form***
### `If + past simple, + subject + would have + past participle`

Si usa per immaginare ***come cambierebbe il presente*** se il ***passato fosse stato diverso***

**REMEMBER: Would can be used with `should/could/might`**

**EXAMPLE: If my English was/were better, I could've got a better job**
